# Cottagecore Living 1.0.0

The first release: 285 cosy decorations for cottage interiors and gardens in five themed sets (Strawberry Cottage,
Lavender Home, Pink Garden, Fairycore and Vintage Cottage), tablecloths, seasonal decor that changes with the year,
and the Decoration Collection Book to track your collection.

Available for:

- Minecraft 1.20.1: Fabric and Forge
- Minecraft 1.21.1: Fabric and NeoForge
- Minecraft 26.2: Fabric and NeoForge
- Minecraft 26.3: Fabric and NeoForge

Install it on both the server and every client. The Fabric files need Fabric API.
